AI Агент-аналитик данных - веб-приложение на Streamlit для автоматического анализа табличных данных с помощью LLM-агента.

Задание 3 — Мини-продукт с LLM-аналитикой

Как работает агент

1. Пользователь загружает CSV или Excel файл через интерфейс
2. Приложение показывает превью данных и базовые метрики (строки, столбцы, пропуски)
3. Пользователь может написать дополнительную инструкцию (например: "найди топ-10 аномалий")
4. При нажатии кнопки "Запустить анализ" — LLM-агент начинает работу:
   - Агент получает только схему датасета (названия колонок и типы данных)
   - Агент сам пишет Python-код и выполняет его через инструмент `execute_python_code`
   - На основе реальных результатов выполнения кода агент пишет отчёт на русском языке
5. В браузере отображается подробный отчёт и графики


Ключевые особенности

- Агентный подход: LLM сама решает какой код написать и выполняет его через `@tool`
- LLM через API программно** — используется Groq API через `LiteLLMModel`, без ручного веб-интерфейса ChatGPT/Claude
- Реальные данные: модель не получает готовую статистику в промпте — только схему
- Поле для инструкции: пользователь может указать на что обратить внимание
- Агентный фреймворк** — используется `smolagents` (HuggingFace) с `CodeAgent`
- Защита от prompt injection: встроенная проверка пользовательского ввода

Как запустить локально
1. Установить зависимости

```
pip install -r requirements.txt
```

2. Создать файл `.streamlit/secrets.toml` и добавить ключ:

```toml
GROQ_API_KEY = "ваш_ключ"
```

3. Запустить приложение

```
streamlit run app.py
```

4. Открыть в браузере
http://localhost:8501


Используемые технологии

- Язык: Python 3
- Веб-фреймворк: Streamlit
- Агентный фреймворк: smolagents (HuggingFace) — CodeAgent
- LLM: Groq API (модель llama-4-scout-17b)
- Инструмент агента: `execute_python_code` (@tool) — интерпретатор Python-кода
- Защита: проверка prompt injection через regex
