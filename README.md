### Задание 3 — Мини-продукт с LLM-аналитикой (Веб-интерфейс: страница Streamlit)

##### Задание

Веб-приложение на веб-странице Streamlit, которое позволяет любому пользователю загрузить CSV-файл и автоматически проводит его анализ с помощью LLM через API (программно). Модель использует инструменты (tool use) для получения статистики и формулирует выводы на русском языке.

##### Ссылка на приложение

[Открыть приложение](https://8xg3uskwpxpuygj2jbtdpc.streamlit.app/)

##### Как работает:

1. Пользователь загружает CSV-файл
2. Приложение показывает превью данных и базовые метрики
3. При нажатии кнопки "Запустить AI-анализ" — данные отправляются в LLM
4. LLM вызывает инструменты для получения реальной статистики:
   - `get\_basic\_stats` — считает строки, столбцы, пропуски, дубликаты
   - `get\_numeric\_summary` — вычисляет среднее, минимум, максимум, стандартное отклонение
 - `get\_top\_categories` — находит топ-3 самых частых значений в текстовых столбцах
5. На основе результатов инструментов модель пишет структурированный аналитический отчёт на русском языке: описание датасета, ключевые метрики, наблюдения и рекомендации
6. Дополнительно выводится таблица с числовой статистикой

##### Файлы в репозитории

```
LR3/

```

##### Как запустить локально

###### 1\. Установить зависимости

```bash
pip install -r requirements.txt
```

###### 2\. Запустить приложение

```bash
streamlit run app.py
```

###### 3\. Открыть в браузере

```
http://localhost:8501
```



* **Фреймворк:** Streamlit
* **API:** Groq (модель llama-3.1-8b-instant)
* **Tool use:** get\_basic\_stats, get\_numeric\_summary, get\_top\_categories
* **Деплой:** Streamlit Cloud
