# Задание 3 — AI Аналитик данных (Streamlit)

## Задание

Веб-приложение на Streamlit, которое принимает CSV-файл от пользователя и автоматически проводит его анализ с помощью LLM через API. Модель использует инструменты (tool use) для получения статистики и формулирует выводы на русском языке.

## Ссылка на приложение

[Открыть приложение](https://ваша-ссылка.streamlit.app)

## Как работает приложение

1. Пользователь загружает CSV-файл
2. Приложение показывает превью данных и базовые метрики
3. При нажатии кнопки "Запустить AI-анализ" — данные отправляются в LLM
4. LLM вызывает инструменты: `get_basic_stats`, `get_numeric_summary`, `get_top_categories`
5. На основе результатов инструментов модель пишет аналитический отчёт на русском языке

## Как запустить локально

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

### 2. Запустить приложение

```bash
streamlit run app.py
```

### 3. Открыть в браузере

```
http://localhost:8501
```

- **Фреймворк:** Streamlit
- **API:** Groq (модель llama-3.1-8b-instant)
- **Деплой:** Streamlit Cloud
